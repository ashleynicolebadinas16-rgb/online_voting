# 🧾 Contributing Guide

Thank you for contributing to the **Online Voting System** project!  
Please follow the standards and workflow below to keep our project consistent and secure.

---

## 🔀 Branch Strategy

- **main** — Protected and stable branch for releases only.  
- **dev** — Development branch where new features are merged.  
- **feature/*** — Feature branches created from `dev` for specific tasks.  
  - Example: `feature/add-candidate-form`  
- **bugfix/*** — Branch for bug fixes.  
  - Example: `bugfix/fix-login-error`
